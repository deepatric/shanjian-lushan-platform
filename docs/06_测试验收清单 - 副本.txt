
测试验收清单
1. 主流程验收
[ ] 匿名用户可进入主地图页
[ ] 匿名用户可搜索、筛选、查看详情
[ ] 匿名用户点击上传或导出时被引导登录
[ ] 注册用户可登录
[ ] 注册用户可收藏地点
[ ] 注册用户可提交 UGC
[ ] 注册用户可提交导出申请
[ ] 管理员可独立登录
[ ] 管理员可审核、编辑并发布 UGC
[ ] 管理员可审批导出申请
2. 地图与时间轴
[ ] 三类点视觉区分明确
[ ] 底图三种切换正常
[ ] 时间轴自动播放正常
[ ] 手动拖动时间轴后地图变化正确
[ ] 关键节点飞跃触发正确
[ ] 多点同现时无严重遮挡
[ ] 2–3 个重点地点可查看多时间事件
3. 搜索与筛选
[ ] 可搜索地点
[ ] 可搜索人物
[ ] 可搜索事件
[ ] 人物可反查相关地点
[ ] 事件可反查相关地点
[ ] 支持类别、时间、区域、关键词筛选
4. 详情与内容
[ ] 详情窗包含固定模块
[ ] 图片可正常展示
[ ] 来源与备注可查看
[ ] AI 场景图有明确标注
[ ] 不同点类详情展示无错误
5. UGC 与审核
[ ] 新地点提交必填校验正确
[ ] 图片上传校验正确
[ ] 未审核 UGC 不进入公开前台
[ ] 审核通过后可发布
[ ] 驳回后用户可查看原因
[ ] 审核日志完整
6. 账号与权限
[ ] 普通用户与管理员登录入口分离
[ ] 普通用户无法访问后台接口
[ ] 管理员注册需邀请码或审核
[ ] 关键接口未授权时拒绝访问
7. 个人中心
[ ] 我的收藏显示正确
[ ] 我的提交显示正确
[ ] 我的导出申请显示正确
[ ] 消息通知可查看
8. 非功能验收
[ ] 首屏加载可接受
[ ] 动画无明显卡顿
[ ] 文本与背景对比度合格
[ ] 不仅依赖颜色区分类别
[ ] 移动端可浏览、搜索、查看详情
9. 明确不纳入首版的测试项
完整故事模式
复杂空间分析
AI 智能问答
AR
UE5 场景
